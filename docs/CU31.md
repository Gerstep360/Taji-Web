# CU31 · Reportes y consultas

## Corrección del dictado (2 de noviembre)

El selector es **siempre visible**, incluso antes de pedir permisos. **Elegir micrófono** actualiza los dispositivos disponibles. Se reemplazó `SpeechRecognition` por [RecordRTC](https://github.com/muaz-khan/RecordRTC), integrado en el servicio Angular y cargado solo al grabar. Captura la entrada seleccionada como WAV mono PCM16 de 16 kHz. No depende del servicio de reconocimiento del navegador.

Flujo: elegir micrófono → **Grabar** → **Transcribir** → revisar texto → **Consultar**. Al alcanzar 30 segundos se pausa y silencia la captura; no se envía automáticamente. **Descartar grabación** libera los tracks sin enviar audio. Se liberan también al salir o cambiar de condominio. En LAN se necesita HTTPS; `localhost` también es válido. Ninguna librería puede evadir esta restricción del navegador.

La prueba E2E usa Web Audio sintético con RecordRTC real y desactiva `SpeechRecognition`. Comprueba selector previo al permiso, selección de dispositivo, WAV enviado y revisión antes de consultar. Pasó en Edge y en el Opera instalado (perfil temporal, sin acceder a pestañas personales). NVIDIA también se probó con una frase sintetizada por Microsoft Sabina: «Mostrar incidencias pendientes del condominio», transcrita correctamente por el servicio real. Esto no sustituye probar el micrófono físico del usuario.

Disponible en **Reportes y analítica → Reportes y consultas**, ruta `/reportes`.
El paquete está en `src/app/paquetes/paquete6_reportes_analitica/cu31_reportes/`.

## Experiencia

- Consulta las fuentes publicadas por el backend: columnas, tipos, operadores y opciones se construyen con el catálogo, no con listas duplicadas.
- Permite elegir columnas, agregar hasta ocho filtros, ordenar y paginar. Editar criterios invalida la vista previa para evitar descargar datos distintos de los revisados.
- Exporta Excel, CSV o HTML para impresión. La descarga contiene todos los resultados filtrados, no solo la página actual; respeta el límite del servidor.
- Permite escribir una consulta o dictarla, revisar el texto y pulsar **Consultar**. La fuente y filtros interpretados quedan visibles y editables.
- El resumen se lee únicamente al solicitarlo. Cambiar de condominio o abandonar la página detiene el audio y descarta respuestas pendientes.
- Interfaz responsive con el layout, colores, iconos y sesión existentes de Taji; carga diferida del paquete.

## Contrato e integración

`ReportsApi` usa el cliente HTTP central y `API_ENDPOINTS.reports = '/cu31/'`, por lo que conserva la URL de API configurada desde `.env`, credenciales, contexto de condominio, renovación de sesión y timeout. No hay IP nueva ni claves en el paquete.

| Operación | Endpoint |
| --- | --- |
| Catálogo | `GET /api/v1/cu31/catalog/` |
| Vista previa | `POST /api/v1/cu31/preview/` |
| Exportación binaria | `POST /api/v1/cu31/export/` |
| Audio WAV a texto | `POST /api/v1/cu31/transcribe/` |
| Consulta textual / dictada | `POST /api/v1/cu31/voice-query/` |
| Resumen para lectura | `POST /api/v1/cu31/voice-narrate/` |

La respuesta de `voice-query/` incluye `report_request` con `source`, `columns`, `filters`, `ordering`, `title`, `page` y `page_size`. Ambos clientes reutilizan ese contrato para paginar y exportar exactamente la consulta interpretada. Se añadió este campo al backend sin sustituir su lógica de reportes.

Los roles visibles coinciden con `CanAccessReports`: `admin`, `administrador`, `superadmin`, `seguridad`, `operador` y superusuarios. El backend sigue siendo la autoridad y exige un condominio activo; no se amplió el acceso a otros roles.

## Voz y privacidad

La interpretación del texto para elegir fuente/filtros sigue siendo el servicio local de CU31. La nueva transcripción envía un WAV multipart al backend, que usa la clave NVIDIA existente en `.env`, nunca expuesta a Angular. El modelo Omni procesa el audio mediante `audio_url` en base64, según la [documentación oficial](https://docs.nvidia.com/nim/vision-language-models/1.7.0/examples/nemotron-3-nano-omni-30b-a3b-reasoning/api.html). Devuelve texto para revisión, no ejecuta el reporte automáticamente.

La interfaz avisa que el audio se envía a Taji y NVIDIA al pulsar Transcribir. Taji no persiste el audio ni registra su contenido o claves. El endpoint exige sesión y acceso a reportes del condominio; limita a seis transcripciones por minuto por usuario, WAV de hasta 30 segundos y 1,1 MB, valida el formato real y controla el timeout del proveedor. El cliente espera hasta 45 segundos; el proveedor tiene un timeout de 35 segundos. Se deben reiniciar backend y servidor Web si siguen sirviendo una versión anterior.
