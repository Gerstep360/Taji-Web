# CU31 · Reportes y consultas

Disponible en **Reportes y analítica → Reportes y consultas**, ruta `/reportes`.
El paquete está en `src/app/paquetes/paquete6_reportes_analitica/cu31_reportes/`.

## Experiencia

- Consulta las fuentes publicadas por el backend: columnas, tipos, operadores y opciones se construyen con el catálogo, no con listas duplicadas.
- Permite elegir columnas, agregar hasta ocho filtros, ordenar y paginar. Editar criterios invalida la vista previa para evitar descargar datos distintos de los revisados.
- Exporta Excel, CSV o HTML para impresión. La descarga contiene todos los resultados filtrados, no solo la página actual; respeta el límite del servidor.
- Permite escribir una consulta o dictarla, revisar el texto y pulsar **Consultar**. La fuente y filtros interpretados quedan visibles y editables.
- El resumen se lee únicamente al solicitarlo. Cambiar de condominio o abandonar la página detiene el audio y descarta respuestas pendientes.
- Interfaz responsive con el layout, colores, iconos y sesión existentes de Taji; carga diferida del paquete.

## Contrato e integración

`ReportsApi` usa el cliente HTTP central y `API_ENDPOINTS.reports = '/cu31/'`, por lo que conserva la URL de API configurada desde `.env`, credenciales, contexto de condominio, renovación de sesión y timeout. No hay IP nueva ni claves en el paquete.

| Operación | Endpoint |
| --- | --- |
| Catálogo | `GET /api/v1/cu31/catalog/` |
| Vista previa | `POST /api/v1/cu31/preview/` |
| Exportación binaria | `POST /api/v1/cu31/export/` |
| Consulta textual / dictada | `POST /api/v1/cu31/voice-query/` |
| Resumen para lectura | `POST /api/v1/cu31/voice-narrate/` |

La respuesta de `voice-query/` incluye `report_request` con `source`, `columns`, `filters`, `ordering`, `title`, `page` y `page_size`. Ambos clientes reutilizan ese contrato para paginar y exportar exactamente la consulta interpretada. Se añadió este campo al backend sin sustituir su lógica de reportes.

Los roles visibles coinciden con `CanAccessReports`: `admin`, `administrador`, `superadmin`, `seguridad`, `operador` y superusuarios. El backend sigue siendo la autoridad y exige un condominio activo; no se amplió el acceso a otros roles.

## Voz y privacidad

El backend CU31 interpreta texto con su servicio local de reglas; **no es una integración nueva con NVIDIA ni transcripción de audio en Django**. El navegador convierte la voz en texto. El micrófono requiere un navegador compatible y un contexto seguro (HTTPS o localhost); en LAN por HTTP se puede escribir normalmente. La disponibilidad y el procesamiento externo dependen del servicio de voz del navegador.

No se envían grabaciones a Taji. El resumen usa la síntesis de voz disponible en el navegador. La consulta escrita sigue funcionando sin micrófono ni síntesis.
